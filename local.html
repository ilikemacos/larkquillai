LarkquillAI Local

Private, offline LarkquillAI that runs on your own computer. No account and no internet needed, and nothing you type leaves your device. Works with Ollama, LM Studio and llama.cpp.

Local 4B

Light and quick. Fits most laptops.

Download 4B (drag into LM Studio)GitHub parts
  • 2.7 GB · one .gguf
  • 8 GB RAM computer

LM Studio — drag and drop

Click Download 4B (drag into LM Studio). When the .gguf finishes, drag that file onto the LM Studio window (or into My Models). No convert step. Optional system prompt: see the model guide.

macOS / Linux (Terminal, needs Ollama)

curl -fsSL https://github.com/ilikemacos/larkquillai/releases/download/local-v1/install.sh | sh -s -- 4b

Windows (PowerShell, needs Ollama)

$env:LARKQUILL_SIZE='4b'; irm https://github.com/ilikemacos/larkquillai/releases/download/local-v1/install.ps1 | iex

Installs into a normal folder: ~/LarkquillAI-Local (Windows: %USERPROFILE%\LarkquillAI-Local). Then double-click Run LarkquillAI Local 4B.command (Mac) or Run LarkquillAI Local 4B.bat (Windows). Ollama parts if you prefer by hand: part 1 · part 2

Local 8B

Smarter answers, writing and code. Needs more memory.

Download 8B (drag into LM Studio)GitHub parts
  • 5.3 GB · one .gguf
  • 16 GB RAM computer

LM Studio — drag and drop

Same as 4B: download the one .gguf, then drag it into LM Studio.

macOS / Linux (Terminal, needs Ollama)

curl -fsSL https://github.com/ilikemacos/larkquillai/releases/download/local-v1/install.sh | sh -s -- 8b

Windows (PowerShell, needs Ollama)

$env:LARKQUILL_SIZE='8b'; irm https://github.com/ilikemacos/larkquillai/releases/download/local-v1/install.ps1 | iex

Same visible folder. Double-click Run LarkquillAI Local 8B.command / .bat. Ollama parts: part 1 · part 2 · part 3

After installing with Ollama

Open ~/LarkquillAI-Local and double-click the Run file — or use Terminal:

ollama run larkquill-local:4b

Use larkquill-local:8b for the 8B. Add --think=false for faster, direct answers.

Why two download styles?

GitHub Releases allow 2 GB per file, so the Larkquill-named builds are split into parts for Ollama. LM Studio wants one .gguf you can drag and drop, so those buttons download a matching upstream Q4_K_M file in a single request (same weights; Apache-2.0). Full steps: model guide.

LarkquillAI Local runs small open models on your computer, so answers are simpler than the online chat and it can't browse the web.
