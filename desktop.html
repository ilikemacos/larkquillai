LarkquillAI for desktop

Windows and macOS. The app updates itself automatically when a new version is out.

macOS (Terminal)

curl -fsSL https://ilikemacos.github.io/larkquillai/install.sh | sh

Windows (PowerShell)

irm https://ilikemacos.github.io/larkquillai/install.ps1 | iex

Or download the installers from the latest release.
